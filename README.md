# systems-architecture

АСиП. Сессионное задание (vo_PJ).

Репозиторий содержит ответы на экзаменационные задания по дисциплине
«Архитектура сервисов и приложений». Работы носят аналитический и
архитектурный характер: в них рассматриваются рефакторинг системы управления
онлайн-курсами, архитектура сервиса бронирования ресторанов, применение
принципов чистой архитектуры и повышение наблюдаемости контейнерной системы.

Основные материалы расположены в каталоге `tasks/`. Для первого задания также
добавлена UML-диаграмма в формате Draw.io и PNG-изображение.
